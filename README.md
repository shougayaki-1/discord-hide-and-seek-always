# リアル隠れ鬼ごっこBot

Discord上でリアル隠れ鬼ごっこの進行を総合的にサポートするために作られたBotです。参加者の募集から、複雑なチーム分け、専用チャンネルの自動生成、ゲーム中のイベント発生、結果発表と後片付けまで、ゲームのすべてを自動化・半自動化します。

## 主な機能

*   **簡単な参加者管理**: リアクション一つで誰でも気軽に参加・キャンセルが可能です。
*   **柔軟な自動チーム分け**: 参加人数に応じて、奇数でも柔軟にペアまたはトリオのチームを自動で編成します。
*   **専用チャンネルの自動生成＆削除**: ゲーム開始時に各チーム専用のプライベートなテキスト/ボイスチャンネルを自動で作成し、ゲーム終了後にはすべて自動で削除してサーバーを綺麗に保ちます。
*   **直感的なボタン操作**: コマンドに不慣れな人でも、ボタンを押すだけで「ゲーム開始」や「捕獲報告」といった主要な操作が可能です。
*   **Googleスプレッドシート連携ミッション**: プログラミング知識がなくても、スプレッドシートを編集するだけでゲーム中に発生するミッションを自由に追加・変更できます。
*   **カスタマイズ可能なイベント**: 写真提出のリマインド間隔や、ミッションの発令頻度をゲームごとに細かく設定できます。
*   **ポイントシステムと自動結果発表**: 捕獲数に応じたポイントを自動で集計し、ゲーム終了時にランキング形式で結果を発表します。

## 導入・設定方法

このBotをあなたのサーバーで動かすには、いくつかの設定が必要です。

### 事前準備

*   [Node.js](https://nodejs.org/) (v16.9.0以上) がインストールされた環境
*   Discordアカウントと、Botをテストするための自分専用のDiscordサーバー

### 1. BotをDiscordに登録する

1.  **[Discord Developer Portal](https://discord.com/developers/applications)**にアクセスし、"New Application"から新しいアプリケーションを作成します。
2.  左側メニューの「Bot」タブに移動し、「Add Bot」をクリックしてBotユーザーを作成します。
3.  **トークンを取得**: 「Reset Token」をクリックしてBotのトークンを生成し、安全な場所にコピーしておきます。（**このトークンは絶対に公開しないでください**）
4.  **サーバーへ招待**:
    *   左側メニューの「OAuth2」→「URL Generator」に移動します。
    *   SCOPESで `bot` と `applications.commands` にチェックを入れます。
    *   BOT PERMISSIONSで**「管理者 (Administrator)」**にチェックを入れるのが最も簡単です。（※権限を細かく設定したい場合は、「チャンネルの管理」「ロールの管理」を含む必要な権限をONにしてください）
    *   生成されたURLをブラウザで開き、Botをあなたのサーバーに招待します。

### 2. Google APIとスプレッドシートを設定する

1.  **ライブラリをインストール**: プロジェクトフォルダのターミナルで、以下のコマンドを実行します。
    ```bash
    npm install discord.js google-spreadsheet google-auth-library
    ```
2.  **Google Cloudプロジェクトを作成**:
    *   [Google Cloud Console](https://console.cloud.google.com/)にアクセスし、新しいプロジェクトを作成します。
    *   メニューから「APIとサービス」→「ライブラリ」に進み、`Google Sheets API` と `Google Drive API` を検索して両方を「有効にする」に設定します。
3.  **サービスアカウントを作成**:
    *   「APIとサービス」→「認証情報」→「＋ 認証情報を作成」→「サービスアカウント」を選択します。
    *   適当な名前（例: `onigokko-bot-sheet-editor`）を付けて作成します。**ロールは不要**です。
4.  **認証キー（JSONファイル）をダウンロード**:
    *   作成したサービスアカウントをクリックし、「キー」タブ→「鍵を追加」→「新しい鍵を作成」を選択します。
    *   キーのタイプで「JSON」を選び、作成ボタンを押すと認証情報ファイルがダウンロードされます。
    *   ダウンロードしたファイルの名前を `google-credentials.json` に変更し、このプロジェクトのルートフォルダ（`index.js`と同じ場所）に置きます。
5.  **スプレッドシートを準備**:
    *   [Googleスプレッドシート](https://docs.google.com/spreadsheets/u/0/)で新しいシートを作成します。
    *   シートのURL（`https://docs.google.com/spreadsheets/d/【この部分がID】/edit`）から**シートID**をコピーします。
    *   右上の「共有」ボタンを押し、`google-credentials.json` の中に記載されている `client_email` のメールアドレスを追加し、権限を**「編集者」**に設定します。
    *   シートの1行目に、以下のヘッダーをA列から順番に設定します。
        | A列 | B列 | C列 |
        | :--- | :--- | :--- |
        | `content` | `points` | `used` |
    *   2行目以降に、ミッションの内容と達成ポイントを自由に追加してください。`used`列はBotが自動で書き込むので空のままにします。

### 3. Botプロジェクトを設定する

1.  プロジェクトフォルダに `config.json` という名前のファイルを作成し、以下の内容を記述します。

    ```json
    {
        "clientId": "あなたのBotのクライアントID",
        "token": "あなたのBotのトークン",
        "guildId": "あなたのテストサーバーのID",
        "spreadsheetId": "あなたのGoogleスプレッドシートのID"
    }
    ```
    *   `clientId`: Discord Developer Portalの「General Information」ページにある `APPLICATION ID` です。
    *   `token`: ステップ1で取得したBotのトークンです。
    *   `guildId`: (任意ですが推奨) テストサーバーのIDです。サーバーアイコンを右クリックしてコピーできます。（※Discordの「開発者モード」を有効にする必要があります）
    *   `spreadsheetId`: ステップ2で取得したGoogleスプレッドシートのIDです。

2.  `index.js` と `package.json` をプロジェクトフォルダに配置します。

3.  ターミナルで以下のコマンドを実行して、Botを起動します。
    ```bash
    node index.js
    ```
    「(Bot名)としてログインしました！」と表示されれば成功です。

## 使い方 (コマンド一覧)

### 【管理者 / ゲームマスター向け】

| コマンド | 説明 | オプション |
| :--- | :--- | :--- |
| `/game-recruit` | 参加者の募集を開始します。 | `title` (必須), `description` (任意) |
| `/game-set-teams` | 募集を締め切り、チーム分けとゲームの設営を行います。<br>**(管理者権限が必要)** | `oni-team-count` (必須), `time-limit` (必須), `enable-missions` (任意), `photo-remind-interval` (任意), `mission-interval-min` (任意), `mission-interval-max` (任意) |
| `/game-end` | 進行中のゲームを強制終了します。 | なし |

### 【鬼チーム向け】

| 操作 | 説明 |
| :--- | :--- |
| `🤚 捕獲報告` ボタン | コントロールパネルのボタンを押し、表示されるメニューから捕獲した逃走者を選択します。 |

### 【全参加者向け】

| 操作 | 説明 |
| :--- | :--- |
| `👍` リアクション | 募集メッセージにリアクションを付けることで、ゲームに参加/キャンセルできます。 |

### 【テスト用】

| コマンド | 説明 |
| :--- | :--- |
| `/ping` | Botがオンラインか確認します。「Pong!」と返れば正常です。 |

## ゲームの基本的な流れ

1.  誰かが `/game-recruit` で参加者を募集します。
2.  参加したいメンバーは募集メッセージに 👍 リアクションを付けます。
3.  管理者が `/game-set-teams` で各種設定を行い、チームを確定させます。
    *   この時点で、各チーム専用のプライベートチャンネルが作成されます。
4.  ゲームマスター（`set-teams`コマンド実行者）がコントロールパネルの「▶️ ゲーム開始」ボタンを押すと、ゲームがスタートします。
5.  ゲーム中は、設定に応じて写真リマインドやミッションが自動でメインチャンネルに投稿されます。
6.  鬼は逃走者を捕まえたら、「🤚 捕獲報告」ボタンから報告します。
7.  以下のいずれかの条件でゲームが終了します。
    *   設定した制限時間が経過する。
    *   全ての逃走者が捕まる。
    *   管理者が `/game-end` コマンドを実行する。
8.  ゲーム終了後、メインチャンネルにポイント集計された最終結果が発表され、専用チャンネルやロールはすべて自動で削除されます。

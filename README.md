# リアル隠れ鬼ごっこBot

Discord上で「リアル隠れ鬼ごっこ」の進行を総合的にサポートするBotです。参加者の募集から、ペア固定を考慮したチーム分け、専用チャンネルの自動生成、ゲーム中のミッション/写真リマインド、ポイント集計と結果発表、後片付けまでを自動化・半自動化します。操作はすべて**ボタンとモーダル**で完結します。

## 主な機能

*   **ボタンでの参加者管理**: 募集パネルの「👍 参加/取消」ボタンで気軽に参加・キャンセルできます。Discordアカウントを持たない同伴者は「👤 ゲスト追加」で登録できます。
*   **ペア固定 & 自動チーム分け**: 「🤝 ペアを組む」で指定した相手とは必ず同じチームになります。1チームの人数目安を設定すると、ペアの繋がりを保ったまま自動でチームを編成します。
*   **専用チャンネルの自動生成 & 片付け**: チーム確定時に「全体連絡」「写真共有」と各陣営の作戦室（テキスト/ボイス）を自動作成。終了時は「チャンネルを残す」「クリーンアップ（全削除）」を選べます。
*   **直感的なボタン操作**: 「▶️ ゲーム開始」「🤚 捕獲報告」「🪙 ポイント操作」「📝 ミッション追加」などコマンドを覚えずに操作できます。
*   **ミッション機能**: 一定間隔（最小〜最大のランダム）で逃走者へミッションを自動発令します。内蔵の固定ミッションに加え、ホストがその場でミッションを手動追加できます。
*   **カスタマイズ可能なイベント**: 制限時間、鬼チーム数、1チーム人数、写真リマインド間隔、ミッション発令間隔をゲームごとに設定できます。
*   **ポイント & 自動結果発表**: 捕獲（+100pt）やホストによる加点を集計し、終了時にランキングを発表します。

## 導入・設定方法

### 事前準備

*   [Node.js](https://nodejs.org/) (v18 以上を推奨。Dockerでは `node:22` を使用)
*   Discordアカウントと、Botを動かすDiscordサーバー

### 1. BotをDiscordに登録する

1.  **[Discord Developer Portal](https://discord.com/developers/applications)** で "New Application" からアプリケーションを作成します。
2.  「Bot」タブでBotユーザーを作成し、「Reset Token」でトークンを取得します（**トークンは絶対に公開しないでください**）。
3.  **Privileged Gateway Intents**: 「Bot」設定の `SERVER MEMBERS INTENT` と `MESSAGE CONTENT INTENT` を **ON** にします（メンバー取得・メッセージ内容に必要）。
4.  **サーバーへ招待**:
    *   「OAuth2」→「URL Generator」で SCOPES に `bot` と `applications.commands` をチェック。
    *   BOT PERMISSIONS は **「管理者 (Administrator)」** が最も簡単です（個別設定する場合は「チャンネルの管理」「ロールの管理」を含めてください）。
    *   生成されたURLでBotをサーバーに招待します。

### 2. 環境変数を設定する

プロジェクトルートに `.env` ファイルを作成し、以下を記述します（`dotenv` で読み込まれます）。

```env
DISCORD_TOKEN=あなたのBotトークン
DISCORD_CLIENT_ID=あなたのアプリケーションID
# 任意: ヘルスチェック用HTTPサーバのポート（既定 8000）
PORT=8000
```

*   `DISCORD_CLIENT_ID`: Developer Portal の「General Information」の `APPLICATION ID`。
*   スラッシュコマンドは起動時にグローバル登録されます。

### 3. 初回セットアップ

1.  [Node.js](https://nodejs.org/) をインストールします。
2.  このリポジトリを `git clone`（またはZIPでダウンロード）します。
3.  リポジトリのルートに `.env` ファイルを作成し、上記の `DISCORD_TOKEN` / `DISCORD_CLIENT_ID` を設定します。
4.  OSに応じた起動ファイルを実行します（下記「起動する」参照）。

依存パッケージのインストール（`npm install`）は起動ファイルが自動で行うため、手動で実行する必要はありません。

### 4. 起動する

このBotは**自宅PC上で、遊ぶときだけ起動し、遊び終わったら終了する**運用を想定しています。ゲームの状態はメモリ上にのみ保持されるため、Botを終了すると進行中のゲームはリセットされます。

#### Windows

`start-windows.bat` を**ダブルクリック**します。

#### macOS

`start-mac.command` を**ダブルクリック**します。

> 初回のみ、Gatekeeperにより「開発元を確認できないため開けません」と警告されることがあります。その場合はFinderでファイルを右クリック（Controlキー+クリック）→「開く」を選び、表示されるダイアログで再度「開く」を選択してください。

いずれも、起動時に以下を自動で確認・実行します。

*   スクリプト自身の場所（このリポジトリのルート）に移動
*   Node.js / npm が使用可能か確認（無ければエラーを表示して終了）
*   `.env` が存在するか確認（無ければエラーを表示して終了。内容は表示しません）
*   依存パッケージ（`node_modules`）が無い・古い場合は `npm install` を自動実行
*   `npm start`（= `node index.js`）でBotを起動

「(Bot名)としてログインしました！」と表示されれば成功です。`http://localhost:8000/` でヘルスチェック（準備完了なら 200、未準備なら 503）が確認できます。

#### 終了方法

起動したターミナル（Windowsはコマンドプロンプト、macOSはターミナル）で **`Ctrl+C`** を押すか、ウィンドウを閉じるとBotが終了します。

*   ゲームの状態はメモリ上にのみ存在するため、**Botを終了すると進行中のゲームはリセットされます**（次に起動したときは新しいゲームとして始まります）。
*   Botが異常終了した場合は、ウィンドウが即座に閉じないようにエラー内容と終了コードを表示してから停止します。内容を確認し、必要であれば再度起動してください。

#### 手動で起動する場合（開発者向け）

```bash
npm install
npm start
```

（Linux/共通の `start.sh` も同様の確認を行ったうえで `npm start` を実行します）

#### Docker で動かす場合

```bash
docker build -t hide-and-seek .
docker run --env-file .env -p 8000:8000 hide-and-seek
```

#### トラブルシューティング: macOSで `start-mac.command` が実行できない場合

このリポジトリでは `start-mac.command` に実行権限を設定済みのため、`git clone` 後は通常そのままダブルクリックで実行できます。万が一「実行権限がありません」等のエラーになる場合は、ターミナルで以下を実行してください。

```bash
chmod +x start-mac.command
```

## 使い方 (コマンド一覧)

| コマンド | 説明 |
| :--- | :--- |
| `/game-recruit` | 参加者募集パネルを表示します。実行者がホストになります。 |
| `/game-end` | 進行中のゲーム/募集を強制終了します（ホストまたは管理者）。 |
| `/welcome` | Botの使い方マニュアルを表示します。 |
| `/ping` | 応答テスト。「Pong!」が返れば正常です。 |

ゲーム中の操作（参加・ゲスト・ペア・設定・開始・捕獲報告・ポイント・ミッション追加・再戦・片付け）は、すべてパネル上のボタンとモーダルから行います。

## ゲームの基本的な流れ

1.  ホストが `/game-recruit` を実行し、募集パネルを表示します。
2.  参加者は「👍 参加/取消」を押して参加。必要に応じて「👤 ゲスト追加」「🤝 ペアを組む」を設定します。
3.  ホストは「👑 ホストメニュー」から制限時間・人数・通知間隔などを設定し、「✅ 募集終了＆チーム分け」を押します。
    *   ペア固定を考慮してチームが自動編成され、各陣営の専用チャンネルが作成されます。
4.  各陣営チャンネルで作戦会議をし、ホストが「📢全体連絡」のパネルから「▶️ ゲーム開始」を押すと開始です（チームが不満なら「🔀 チーム再抽選」も可能）。
5.  ゲーム中は設定に応じて写真リマインドとミッションが自動投稿されます。
6.  鬼は逃走者を捕まえたら「🤚 捕獲報告」で報告します（捕まったチームは鬼陣営へ移動）。
7.  次のいずれかで終了します。
    *   制限時間が経過する
    *   逃走者が全員捕まる
    *   ホスト/管理者が `/game-end` を実行する
8.  終了後、ポイントランキングが発表され、「同じチームで再戦」「チームを変えて再戦」「終了（チャンネルを残す/全削除）」を選べます。

## 補足・既知の制約

*   **マルチサーバー対応**: ゲーム状態は `Map<guildId, gameState>` でサーバーごとに独立管理されるため、複数サーバーで同時に別々のゲームを進行できます。
*   状態はメモリ上に保持され**永続化されない**ため、Bot再起動で進行中ゲームはリセットされます（DB等への永続化は未対応）。この仕様上、「遊ぶときだけ起動し、遊び終わったら終了する」運用が前提となります。
*   起動スクリプト（`start-windows.bat` / `start-mac.command` / `start.sh`）は `git pull` 等のコード更新を行いません。最新化したい場合は手動で更新してください。
